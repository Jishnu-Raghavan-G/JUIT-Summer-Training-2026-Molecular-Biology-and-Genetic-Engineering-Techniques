# Plasmids and Vector Systems

## Introduction

A **vector** is a DNA molecule used to carry and introduce a desired DNA fragment into a host cell. Vectors are essential tools in recombinant DNA technology because they provide a way to maintain, replicate, and sometimes express inserted DNA.

One of the most commonly used vectors in molecular biology is the **plasmid**.

## What is a Plasmid?

A plasmid is a small, usually circular, double-stranded DNA molecule found naturally in many bacteria. Plasmids replicate independently of the bacterial chromosome.

Researchers can modify plasmids to carry genes or other DNA sequences of interest.

## Basic Structure of a Plasmid Vector

A typical cloning plasmid contains several important elements:

| Component | Function |
|---|---|
| Origin of replication (ori) | Allows plasmid replication in the host |
| Selectable marker | Allows selection of cells carrying the plasmid |
| Multiple cloning site (MCS) | Contains restriction sites for DNA insertion |
| Insert | Desired DNA fragment introduced into the vector |

A simplified representation is:

             ┌──────────────┐
             │ Selectable   │
             │   marker     │
             └──────┬───────┘
                    │
              ┌─────┴─────┐
              │  Plasmid  │
              │           │
              │    ori    │
              │           │
              │    MCS    │
              └───────────┘
Origin of Replication

The origin of replication (ori) is the region from which plasmid DNA replication begins.

The ori influences:

Whether the plasmid can replicate in a particular host
The number of plasmid copies maintained in the cell
Compatibility with other plasmids
Selectable Marker

A selectable marker allows cells containing the vector to be identified or selected.

A common example is an antibiotic-resistance gene.

After transformation, cells are grown under selective conditions. Cells that have acquired the appropriate plasmid can survive, while cells without it are generally eliminated.

Multiple Cloning Site

The multiple cloning site (MCS) is a short region containing several unique restriction enzyme recognition sites.

It provides convenient locations for inserting foreign DNA into the vector.

The choice of restriction sites depends on:

The vector
The insert
The cloning strategy
Presence or absence of the restriction sites within the desired insert
Cloning Vector vs Expression Vector
Cloning Vector

A cloning vector is mainly designed to maintain and replicate a DNA fragment in a host.

Expression Vector

An expression vector contains additional regulatory elements that allow the inserted gene to be expressed in the host.

Expression vectors may contain elements such as:

Promoter
Ribosome-binding or translation-related elements where appropriate
Transcriptional terminator
Selectable marker
Common Types of Vectors
Vector	General Use
Plasmid	Routine gene cloning and expression
Bacteriophage vector	Cloning larger DNA fragments in suitable systems
Cosmid	Carrying relatively larger DNA fragments
BAC	Large DNA fragment cloning
YAC	Very large DNA fragment cloning

The appropriate vector depends on the size of the DNA fragment and the purpose of the experiment.

Recombinant Plasmid Formation

A simplified cloning workflow is:

Plasmid vector
      ↓
Restriction digestion
      ↓
Open vector DNA

DNA insert
      ↓
Restriction digestion
      ↓
Compatible DNA ends

Vector + Insert
      ↓
DNA ligation
      ↓
Recombinant plasmid

The recombinant plasmid can then be introduced into a suitable host cell through transformation.

Vector Selection

An appropriate vector should be selected based on:

Host organism
Insert size
Desired application
Replication requirements
Selection system
Whether gene expression is required
Available cloning sites
Important Features of a Good Vector

A useful cloning vector generally has:

An origin of replication
A selectable marker
Convenient cloning sites
Suitable size
Stability in the host
Appropriate copy number

For expression applications, appropriate regulatory elements are also required.

Plasmid Copy Number

Plasmids may be maintained at different copy numbers within a host cell.

High-copy plasmids can produce many copies per cell, while low-copy plasmids are maintained at fewer copies.

Copy number can influence plasmid yield and may also affect the stability of certain inserts.

Applications

Plasmid and vector systems are used for:

Gene cloning
Recombinant protein production
Gene expression studies
DNA sequencing preparation
Functional gene studies
Construction of recombinant DNA
Molecular biology research
Practical Workflow
Select a suitable vector.
Identify the desired DNA insert.
Select compatible cloning sites or another cloning strategy.
Prepare the vector and insert.
Join the DNA fragments by ligation or another cloning method.
Introduce the recombinant vector into competent host cells.
Select cells carrying the vector.
Screen the resulting colonies for the desired recombinant construct.
Key Takeaways
Plasmids are commonly used as vectors in recombinant DNA technology.
The origin of replication allows plasmid replication in the host.
Selectable markers help identify cells carrying the vector.
The MCS provides convenient sites for DNA insertion.
Cloning vectors mainly maintain DNA, while expression vectors are designed to support gene expression.
Vector selection depends on the host, insert and experimental objective.
